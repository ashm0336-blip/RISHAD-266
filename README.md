# رشاد — RISHAD

**منظومة رقمية لإدارة العمليات واتخاذ القرار.**

تجمع رشاد الإدارات والأقسام في منصة واحدة، لكل وحدة بياناتها وصلاحياتها المستقلة، ويدخل الجميع بحساب موحد: الخطة التشغيلية والجدول الشهري والمتابعة اليومية والتقارير، والمهام والموظفون والعهد، وأنظمة الاسترشاد والمضبوطات والجائزة، ومؤشرات الأداء داخل كل نظام.

**صاحب المشروع والإشراف على تطويره:** بسام الغزاوي.
