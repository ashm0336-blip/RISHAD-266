## 1) الحزمةُ الإنتاجية (تُعدّ الآن · لا تُنشر)
```bash
bash tools/build_chain.sh <N>                       # بناءٌ حتمي + MANIFEST + pk<N>.prod (حزمةُ الإنتاج بلا أداة الاختبار — tools/prod_strip.py · SOT-173)
python3 tools/release_check.py <N>                   # لا نشرَ بلا دليل
python3 tools/prod_strip.py pk<N> --check            # «… · 0 مخالفة» — وإلا توقّف: لا تغليفَ ولا نشر
python3 tools/pack.py KIVO_<N> pk<N> /mnt/user-data/outputs/KIVO_<N>   # Production_upload.zip · Preview_upload.zip · dist_Candidate.zip · MANIFEST.sha256 · SHA256SUMS
```
المحتوى: **`KIVO_<N>_Production_upload.zip`** — حزمةُ النشر على Production: من `pk<N>.prod` والملفاتُ في جذر الـzip (الغلاف + الأصول المبصومة + الصفحات الكسولة + `_worker.js` + `public/*`) **بلا أداة الاختبار**؛ و`pack.py` يرفض التغليفَ إن غاب `pk<N>.prod` أو لم يكن مشتقّاً من `pk<N>` الحالي (كلُّ ملفٍّ غيرِ العامل = المرشّحُ بايتاً · العاملُ = نزعُ الأداة من عامل المرشّح الحالي بايتاً · لا ملفَّ زائد · يُحلَّل بـnode — `tests/unit/pack_prod.test.mjs`). `KIVO_<N>_Preview_upload.zip` من `pk<N>` **بالأداة — لـPreview وحدها**. `KIVO_<N>_dist_Candidate.zip` أرشيفٌ (`dist/` + البيان + `README`) لا يُسقط. الحزمةُ الإنتاجية هي **نفسُ** حزمة Preview بايتاً **عدا `_worker.js`: أداةُ الاختبار الداخلية (`/api/authz-test`) مستبعَدةٌ منها كوداً** (KIVO_263 · قرارُ المالك في SOT-173 · ADR-036 · `tests/unit/prod_strip.test.mjs`)؛ وما سوى ذلك بلا فرق (لا بناءَ خاصاً بالإنتاج غيرُ هذا الاستبعاد — ADR-002: البيئةُ تُقرّر لا الكود).

## 3) النشر
- **فحصٌ مسبقٌ إلزامي قبل الإسقاط:** `python3 tools/prod_strip.py pk<N> --check` ⇒ «… · 0 مخالفة» (العاملُ بلا الأداة وهو نزعُها من عامل المرشّح الحالي بايتاً · بقيةُ الملفات = المرشّح بايتاً · لا ملفَّ زائد) · `sha256sum -c SHA256SUMS.txt` في مجلد الحزم ⇒ كلُّ سطرٍ OK · والملفُّ الذي سيُسقط هو `KIVO_<N>_Production_upload.zip` نفسُه ببصمته في `SHA256SUMS.txt`. أيُّ مخالفةٍ ⇒ لا نشر.
- Cloudflare → Workers & Pages → المشروع `0` → Deployments → Create deployment → **Production (main)** → إسقاط **`KIVO_<N>_Production_upload.zip`** (من `pk<N>.prod` · المحتوى في الجذر · بلا أداة الاختبار) → Save and deploy. (من هذا المختبر: **لا** — الخيارُ Production محظورٌ في مسار الأتمتة؛ ينفّذه المالك بنفسه.)
- **لا يُرفع `KIVO_<N>_Preview_upload.zip` إلى Production أبداً** (يحمل أداةَ الاختبار — لـPreview وحدها)، ولا `KIVO_<N>_dist_Candidate.zip` (أرشيف — ملفاتُه تحت `dist/`).
