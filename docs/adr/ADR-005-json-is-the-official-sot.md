# ADR-005 — JSON هو المصدر الرسمي للمتطلبات؛ HTML وCSV مخرجات مولَّدة
- الحالة: معتمد · 2026-10-09 · SOT-076 · SOT-128 · SOT-192 (المرجع)
- القرار: `docs/sot/KIVO_MASTER_REQUIREMENTS_v6.json` وحده يُحرَّر (عبر `tools/sot.py`)؛ اللوحة والـCSV يُعاد توليدهما بعد كل تحديث ويُتحقق من تطابقهما (`k243/audit/sot_v6_verify.py`). كل بند يحتفظ بهويته؛ كل تحقق جديد يُضاف تحت `audit_<تاريخ>`/`verifications[]` مع الإصدار والدليل ومستوى التحقق (ساكن/محلي/Preview/إجراء)، ولا يُرفع بند إلى «مكتمل» بلا دليل.
