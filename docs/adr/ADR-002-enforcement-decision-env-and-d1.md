# ADR-002 — قرار الإنفاذ = ENV ∧ D1، وتركيب الحكم deny > unknown > allow
- الحالة: معتمد (KIVO_243) · SOT-008 · SOT-009 · SOT-032 · SOT-033
- السياق: نقل الصلاحيات من النظام القديم (ذرّات page:act) إلى سجل v24.9 بلا كسر Production.
- القرار: الإنفاذ يعمل فقط حين يجتمع متغيّر البيئة `KIVO_AUTHZ_MODE=enforce` وسطر D1 `meta.authz_mode=enforce`؛ غياب أيّهما = النظام القديم حرفاً بحرف. مفتاح الطوارئ: `UPDATE meta SET v='legacy' WHERE k='authz_mode'` (بلا نشر). حكم الطلب: أي رفض يغلب، ثم المجهول (مفتاح غير معرَّف = رفض)، ثم السماح.
- البدائل المرفوضة: علم ENV وحده (لا إيقاف فوري بلا نشر) · علم D1 وحده (Production تقرأ D1 لأجل الإنفاذ بلا حاجة).
- النتائج: Production بلا المتغيّر لا تقرأ D1 لأجل الإنفاذ ولا يتغيّر مسار واحد فيها (مثبت ببوابة k243src 15/0).
- ملاحظة: مسار «فشل قراءة D1» كان يُرجع legacy — عُولج في ADR-003.
