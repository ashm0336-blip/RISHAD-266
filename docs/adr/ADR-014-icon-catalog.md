# ADR-014 — منظومةُ الأيقونات: فهرسٌ واحد يُركَّب عند البناء (AUD-018 · SOT-084 · SOT-152)
- الحالة: معتمد · 2026-10-10 (RM-3 · KIVO_253)
- السياق: 1,306 أيقونةً `<svg>` مضمَّنةً نصّاً داخل قوالب الوحدات الـ14 والغلاف (377 شكلاً مميزاً بعد توحيد الفراغات)؛ الشكلُ الواحد مكرَّرٌ حتى 60 مرة؛ لا فهرسَ ولا اسمَ ولا طريقةَ لتبديل أيقونة في موضعٍ واحد. التدقيقُ (AUD-018) طلب «sprite أو مكوّناً» و«`<svg>` مضمَّنة في القوالب = 0» وفهرساً.
- القرار:
  1. **المصدرُ الواحد** `src/assets/icons/catalog.json`: لكل أيقونة مفتاحٌ `i-xxxxxxxx` = sha1(viewBox + الجسدُ بعد توحيد الفراغات)، وجسدُها، وviewBox، ومواضعُ استعمالها (ملف → عدد). الفهرسُ المرئي `docs/icons.html` مولَّدٌ منه (`tools/icons.py index`).
  2. **القوالبُ تشير ولا تضمّن**: `<svg …سماتُ الموضع… data-i="i-xxxxxxxx"></svg>` — سماتُ الموضع (width/height/class/style/stroke…) تبقى في القالب لأنها قرارُ الموضع لا الأيقونة.
  3. **التركيبُ عند البناء لا عند التشغيل**: `tools/page_modules.py join` (الصفحات) و`tools/build.py render_shell` (الغلاف) يستبدلان كلَّ إشارةٍ بجسدها المضمَّن من الفهرس — فما يصل المتصفح هو الـSVG المضمَّن نفسُه كما كان. **لا `<use>` ولا sprite في المتصفح**: وثائقُ الطباعة (إطاراتُ `bs-print-frame`/`bs-cu-print` المستنسخة من DOM) وملفاتُ التصدير (Blob · 18 وثيقةً مستقلة) تبقى مكتفيةً بذاتها؛ لا طلبَ شبكةٍ إضافياً؛ لا تغييرَ في CSS أو JS التي تلمس `<svg>`.
  4. **الحارس** `tools/icons.py check` (في `npm run build/check` وCI): لا `<svg>` بجسدٍ في القوالب · كلُّ إشارةٍ موجودة · لا يتيمَ في الفهرس · عددُ المواضع مطابق · الفهرسُ المرئي محدَّث.
  5. **الإضافة**: يُكتب الـSVG مضمَّناً في القالب ثم `python3 tools/icons.py extract --src src` ينقله إلى الفهرس ويستبدله بالإشارة (الأيقونةُ المطابقةُ لشكلٍ قائم تأخذ مفتاحَه تلقائياً).
- البدائل المرفوضة: **sprite + `<use href="#id">`** (يكسر وثائقَ الطباعة والتصدير المستنسخة من DOM ما لم يُحقن الـsprite في كل وثيقة — 18 موضعاً هشّاً) · **مكوّنُ أيقونات في زمن التشغيل** (MutationObserver يملأ `svg[data-i]`): يعمل لكنه يضيف خطوةً وتأخيراً في الرسم ويُثقل الغلاف (125 KB فهرساً) أو يحتاج أصلاً إضافياً؛ التركيبُ عند البناء صفرُ كلفةٍ في التشغيل · **ملفُّ sprite خارجي** `/assets/icons.svg#id`: لا يعمل في وثائق `blob:` (أصلٌ معتم) ويضيف طلباً.
- البرهان: `tests/source/k253src.py` (ب): لكل قالبٍ `normalize(materialize(قالب 253)) == normalize(قالب 252)` ولكل صفحةٍ مولَّدة `normalize(صفحة 253) == normalize(صفحة 252)` — الفرقُ الوحيد فراغاتٌ داخل `<svg>` لا تُرسم؛ الغلافُ والصفحاتُ بلا `data-i` ولا `<use>`؛ البوابةُ البصرية (64 شاشة · k253vis) والطباعةُ (k242print) تثبتان التطابقَ بكسلاً.
- النتائج: الفهرسُ والأسماءُ الدلالية (مرحلةٌ تالية: تسميةُ الـ377 مفتاحاً بأسماء مقروءة وربطُها بنظام التصميم `docs/design-system.md`)؛ الأيقوناتُ داخل سلاسل JS في `modules/*/logic.js` (وثائقُ التصدير والطباعة ومكوّناتٌ مولَّدة برمجياً) خارجَ هذه المرحلة — تُفهرَس لاحقاً بالآلية نفسِها عبر دالةٍ `KIVO_ICON(id)` عند الحاجة.
