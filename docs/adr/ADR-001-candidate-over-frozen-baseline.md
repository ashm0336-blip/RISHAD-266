# ADR-001 — كل تطوير مرشّحٌ (Candidate) مستقل فوق أساس مجمَّد
- الحالة: معتمد (قائم منذ KIVO_242؛ مسجَّل هنا) · SOT-001 · SOT-073 · SOT-075
- السياق: المنصة منشورة على Production (KIVO_242) وبياناتها تشغيلية؛ أي تغيير يحتاج طريق رجوع مضموناً.
- القرار: الأساس (KIVO_242) لا يُعدَّل؛ كل مرحلة تُخرج Candidate مرقَّماً (KIVO_243، KIVO_244 …) يُبنى حتمياً ويُسلَّم بحزمة مبصومة (MANIFEST.sha256) ويُختبر على Preview قبل أي اعتماد.
- البدائل المرفوضة: التعديل المباشر على المنشور (لا رجوع) · فرع واحد متدحرج بلا حزم مبصومة (لا إعادة إنتاج).
- النتائج: مجلدات `k242/`, `k243/`, `k244/` + وسوم git بالاسم نفسه؛ Production لا تُلمس إلا باعتماد صريح بعد Preview PASS.
