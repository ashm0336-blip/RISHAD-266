# ADR-008 — dc-runtime: الملف المقروء هو المصدر، ومنطق الصفحات مُصرَّف مسبقاً (CSP بلا unsafe-eval)
- الحالة: معتمد · 2026-10-09 (RM-2 · KIVO_246) · AUD-008 · SOT-048 · ADR-007 (2)
- السياق: `050-dc-runtime.js` كان مولَّداً من TypeScript غير موجود في المستودع؛ وكان يقيّم منطق كل صفحة (`<script data-dc-script>`) ومنطق الغلاف (`shell/xdc/root-logic.js`) بـ`new Function` عند التشغيل، فاحتاجت CSP إلى `'unsafe-eval'` (AUD-006/SOT-048).
- القرار:
  1. الملف المقروء `client/js/050-dc-runtime.js` (1,970 سطراً · غير مصغَّر) هو المصدر المعتمد ويُحرَّر مباشرة؛ تعليقات `// src/*.ts` تحفظ خريطة الوحدات الأصلية. لا إعادة كتابة TypeScript الآن (كلفة بلا عائد مثبت).
  2. البناء (`build.py` · العلامة `"dcLogic": "precompiled"` في blocks.json) يلفّ منطق كل صفحة في دالة عادية `window.__dcLogicDefs[name] = function (DCLogic, StreamableLogic, React) {…}` بالتوقيع نفسه الذي كانت `new Function` تنشئه، ويقدّمها سكربتاً عادياً: في الوضع الكسول ملفاً ذا بصمة `/assets/pages/<name>.logic.<hash>.js` (خريطته `window.__dcLogic` في محمِّل الصفحات) يُحمَّل عند أول فتح للصفحة بالتوازي مع نص الصفحة؛ وفي المونوليث تعريفات مضمَّنة بعد المحمِّل. منطق الغلاف يُصرَّف كذلك (`/assets/js/root-logic.<hash>.js` · الاسمان `Root` و`index`).
  3. dc-runtime يفضّل التعريف المُصرَّف (`hasPrecompiled`)؛ `new Function` تبقى احتياطاً للتطوير بلا تصريف فقط. فشل تحميل سكربت المنطق: 3 محاولات (1·2·4 ث) ثم تبقى الوحدة فارغة بلا غلاف متداخل وتُعاد المحاولة عند الفتح التالي أو بعد 30 ث أو عند `online`.
  4. تُحذف `'unsafe-eval'` من ترويسة CSP في الخادم ومن وسم `<meta>` في الغلاف. `'unsafe-inline'` تبقى إلى خطوة CSP الثانية (nonce للسكربتات المضمَّنة — RM-3).
- البرهان: `k246/tests/k246src.py` (الفرق المعلن بالضبط · جسم كل دالة = سكربت الصفحة حرفاً) · `cfbench/k246logic.mjs` (19 تأكيداً في متصفح حقيقي: 0 مخالفة CSP · 0 `new Function` · الصفحات الخمس عشرة تُرسم · الفقد والعودة · المونوليث) · البوابة الكاملة.
- النتائج: لا تقييم لنص ككود في الإنتاج؛ منطق الصفحات يظهر في أدوات المطوّر كملفات مسمّاة؛ +1 طلب لكل صفحة عند أول فتحها فقط (immutable · سنة)؛ نص الصفحة ما زال يحمل السكربت نصاً (غير منفَّذ) — إزالته من `.dc.txt` تحسين لاحق.
