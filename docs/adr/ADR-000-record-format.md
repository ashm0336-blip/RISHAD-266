# ADR-000 — صيغة سجل القرارات المعمارية
- الحالة: معتمد · 2026-10-09
- كل قرار جوهري ملفٌ `docs/adr/ADR-NNN-<slug>.md` بحقول: الحالة · السياق · القرار · البدائل المرفوضة · النتائج · الأدلة · بنود SOT المرتبطة.
- القرار لا يُعدَّل بعد اعتماده؛ يُستبدل بقرار جديد يشير إليه («يحلّ محلّ ADR-NNN»).
- المصدر الوحيد للمتطلبات هو SOT v6 (`docs/sot/KIVO_MASTER_REQUIREMENTS_v6.json`)؛ الـADR يشرح «لماذا» لا «ماذا».
