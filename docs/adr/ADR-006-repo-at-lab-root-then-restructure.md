# ADR-006 — المستودع عند جذر المختبر الآن، وإعادة الهيكلة إلى الشجرة المستهدفة تدريجياً ببرهان
- الحالة: معتمد · 2026-10-09 (RM-0) · SOT-080 · SOT-136 · AUD-028 · AUD-029
- السياق: البوابة الدائمة (131 حزمة) مرتبطة بمسارات المختبر (`cfbench/`, `registry*/`, `pk*/`)؛ نقلها دفعة واحدة إلى الشجرة المستهدفة يكسر البوابة قبل أن تُثبت شيئاً.
- القرار: git عند جذر المختبر مع `.gitignore` للمخرجات القابلة لإعادة الإنتاج؛ المصدر الحيّ `k244/src`؛ النقل إلى `src/`, `workers/`, `tests/*` يتم في RM-2 خطوة خطوة، وكل خطوة تمرّ بالبوابة أو ببرهان تساوي الناتج (بايتاً).
- النتائج: تاريخ كامل منذ KIVO_242 · CI · مخرجات مبصومة؛ جذر المستودع يبقى مزدحماً مؤقتاً (AUD-029 P2 مفتوح).
