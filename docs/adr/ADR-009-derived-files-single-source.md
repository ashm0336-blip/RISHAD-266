# ADR-009 — الملفات المشتقّة داخل المصدر تُولَّد من مصدر واحد وتُفحص في CI (السجل · الخادم · الصفحات)
- الحالة: معتمد · 2026-10-09 (RM-2 · KIVO_246) · AUD-011 · AUD-007 · ADR-006
- السياق: سجل الصلاحيات v24.9 كان نسختين حرفيتين (واجهة `340-registry-v24-9.js` وخادم `KIVO_REGISTRY_DATA`) بلا رابط آلي؛ الخادم ملف واحد 1.1 MB؛ الصفحات مضغوطة.
- القرار: مصدر الحقيقة لكل مشتقّ ملفٌّ واحد مقروء، و`k246/tools/generate.py` يولّد المشتقّات بايتاً، و`--check` يفشل CI عند أي فرق بين المولَّد والمُلتزَم:
  - `registry/registry-v24.9.json` (بيانات · 269 مفتاحاً · docSha256 الوثيقة) + `registry/engine.js` (المحرّك المشترك) + `registry/targets.json` (ترويسة كل هدف) → `client/js/340-registry-v24-9.js` و`workers/parts/004-registry-2.js`.
  - `workers/parts/*.js` بترتيب `workers/parts.json` (64 جزءاً بحسب لافتات الخادم) → `root/_worker.js`. التحرير في الأجزاء؛ الملف المضموم يبقى مُلتزَماً (الحزمة والعُدّة تقرآنه) ومحروساً بالفحص.
  - `modules/<slug>/{meta.json,helmet.css,view.html,logic.js}` → `client/pages/<name>.dc.html` (esbuild minify للصفحات التي كان سكربتها مضغوطاً — ADR-007).
- البدائل المرفوضة: توليد أثناء البناء فقط دون التزام المشتقّ (يكسر العُدّة والبوابة التي تقرأ `root/_worker.js` مباشرة) · ترك النسختين (انحراف صامت).
- النتائج: تغيير السجل أو الخادم أو الصفحات له مكان واحد؛ `generate.py --check` في `build:246` وفي CI؛ `k246src.py (ب)` يثبت 17 مشتقّاً = مصدره.
